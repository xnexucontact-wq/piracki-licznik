# Piracki Licznik — licznik skrzyń do Fortnite

Darmowy program na Windows 10/11, który **sam liczy otwarte skrzynie w Fortnite** z powtórek meczów.

- licznik skrzyń (zwykłe, rzadkie, rozwalone kilofem) liczony automatycznie po każdym meczu
- nakładka nad grą i skróty klawiszowe (~ / F8 = +1 skrzynka, F10 = nakładka)
- mapa skrzyń i trasa z każdego meczu, najlepsze miejsca do lądowania
- szansa na piracki token i postęp questa „rzadkie skrzynie”
- automatyczne aktualizacje

**Strona programu:** https://xnexucontact-wq.github.io/piracki-licznik/

**Pobierz:** [PirackiLicznik.exe (najnowsza wersja)](https://github.com/xnexucontact-wq/piracki-licznik/releases/latest/download/PirackiLicznik.exe)

Fanowski projekt, niezwiązany z Epic Games. Fortnite jest znakiem towarowym Epic Games, Inc.
